# Spec — Bill footer says the bill was made with AnyRent

Issue: #1593 · Status: in-progress · Intent: ./intent.md

## Behavior

1. Web: the receipt slip's last line is `orders.web.receipt.generatedBy`. In Vietnamese: "Hóa đơn được tạo bằng
   ứng dụng AnyRent". The other 11 languages use the iOS text of "Receipt generated by AnyRent software"
   (zh → zh-Hans, zh-TW → zh-Hant). `web.receipt.downloadApp` is removed.
2. iOS: the thermal print's last line is `"Receipt generated by AnyRent software".localized()` (no accents).
   `vi-VN` text of that key: "Hóa đơn được tạo bằng ứng dụng AnyRent".
3. Android: the thermal print's last line is `R.string.receipt_generated_by` in the app language; without the
   app (JVM test) it is the English text. `values-vi` text: "Hóa đơn được tạo bằng ứng dụng AnyRent".
4. No printed bill in web, iOS or Android contains "App Store".

## Out of scope

The shared `packages/ui` `ReceiptPreviewModal` (no app imports it), other bill lines, `locales-pending/`.

## API and data

None.
