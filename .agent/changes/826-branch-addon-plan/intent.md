# Intent — #826 branch add-on needs a multi-branch plan

Part of #823 (owner decision 5, 2026-10-11). A branch add-on (PlanLimitAddon with `outlets > 0`) is only
for a multi-branch plan (Enterprise). Today an admin can give a single-branch shop extra branches through an
add-on, which bypasses the plan line-up. Add-ons for users / products / customers / orders stay as they are,
and existing add-ons are not touched.
